# Reel 1.2.31

Automatic meeting joins are more dependable.

- Reel joins correctly when a browser extension replaces Chrome's new-tab page.
- A join that hits a busy browser is retried in a fresh window instead of being dropped.
- If Reel cannot join or leaves a meeting early, you get a notification with a one-click way to join.
- Slow page reads no longer end a recording early.
